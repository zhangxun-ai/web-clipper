# web-clipper

网页剪存：保存网页和在线文档的正文图片到飞书知识库、Obsidian 或本地。

源码仓库：[zhangxun-ai/web-clipper](https://github.com/zhangxun-ai/web-clipper)。项目名为 `web-clipper`，当前扩展显示名称仍为「文档本地导出」，发布名称独立于仓库名。

一个可直接加载到 Chrome 的文档导出与剪存插件，支持：

- 生财有术、公众号、普通网页、Google Docs 和飞书 `docx/wiki` 的正文图片保存到指定知识库父页面下（需本机飞书 CLI 连接器）
- 飞书 `docx/wiki` 单篇导出 `Markdown / JSON`
- Google Docs 文档单篇导出 `Markdown / JSON`
- 微信公众号单篇文章导出 `Markdown / JSON`
- 飞书 / 微信文章链接列表批量下载
- 微信公众号“种子文章 -> 同号 -> 指定日期范围”批量下载
- 生财课程章节页“一键导出当前专栏”为单个 `Markdown + HTML`

本地 Markdown 导出优先保证正文可读，不追求 100% 样式还原。飞书知识库剪存将可读取的网页正文转换为飞书内容块；飞书源文档直接读取原生块，保留正文、富文本、标题、列表、代码和普通表格结构，图片独立上传，再核对内容和位置。评论、历史版本不在剪存范围内；不支持的资源块会明确提示，不会静默丢弃。

## 项目名称与本地目录

- 新克隆项目默认使用 `web-clipper` 目录；已有本地目录无需改名，GitHub 仓库改名不会要求重新安装扩展。
- 已有克隆可运行 `git remote set-url origin git@github.com:zhangxun-ai/web-clipper.git` 更新远程地址。
- 如果自行移动或重命名本地目录，需要重新加载扩展、核对扩展 ID，并按[连接器说明](docs/feishu-wiki-clip.md#一次性连接)重新注册本机连接器，因为连接器记录了源文件的绝对路径。

## 界面与常用入口

- 打开插件后，先确认当前文章标题，再选择“快速导出”“带图留档”或“Obsidian”，点击主按钮导出；“保存到飞书”是独立的知识库保存入口。
- “自定义导出设置”可调整输出目标和图片选项；右上角设置按钮会直接展开这里。
- 批量链接下载、公众号日期范围下载和生财专栏导出位于“批量与专栏工具”。其中的分类只切换工具，上方始终对应当前网页。
- “Obsidian 目录”用于选择目标文件夹及管理目录授权。选择 Obsidian 导出但尚未配置时，会自动展开并定位到目录入口。
- 飞书保存页依次呈现连接状态、文章和保存位置；开始保存后，进度或结果显示在文章上方。保存成功后只保留一个打开入口，来源与位置收起，可展开修改。批量任务页优先呈现进度、成功、失败和用时，处理详情与运行日志按需展开。

界面审核、验证范围及设计参数见 [UI 审核与优化记录](docs/ui-review.md)。在项目根目录运行 `npm run test:ui` 可单独验证弹窗布局与键盘交互，完整 `npm run test:browser` 也包含该检查。更新后请刷新扩展及源网页。

## 剪存到飞书知识库（0.4.8）

1. 打开要保存的文章或文档，点击插件，在当前页主操作旁点击“保存到飞书”。网页地址自动带入，所有分类共用此入口。读取图文期间保持原网页打开。
2. 首次使用展开“首次连接说明”，在项目目录运行页面给出的安装命令；本机需要已安装并配置 [飞书 CLI](https://github.com/larksuite/cli)。连接器支持 macOS / Linux 上的 Chrome、Edge、Chromium，以及 macOS 上的 Dia（命令加 `--browser dia`），Windows 暂不支持。
3. 页面会自动检查并复用已有授权。仅首次未登录、授权失效或缺少所需权限时，点击“登录飞书”完成授权；之后打开会自动保持登录。连接程序未安装时先完成安装，不需要重复授权。
4. 粘贴知识库中父页面的 `wiki` 链接并确认；也可以展开“从我的知识库选择”，逐层选到父页面，再点“保存到此页下面”。选定后立即记住，下次自动使用，无需重新输入或确认；剪存失败也不会丢失位置。
5. 确认文章和位置，点击一次“保存到飞书”。任务在后台处理，临时请求异常自动恢复；完成后发出“已保存到飞书”桌面通知，点击通知或页面上的“在飞书中打开”即可查看。可以关闭剪存页，读取图文期间保留原网页即可。来源、位置设置和处理细节默认收起，需要时展开。

成功标志：显示“已保存到飞书”，点击“在飞书中打开”可以访问原文的独立副本，而且它位于指定父页面下面。原文不会被移动或修改。

异常处理：

- 原文未开放创建副本：直接读取可访问的正文和图片，重建自己的文档，不需要原生复制权限。
- 普通接口返回“类型 999”的网页书签卡片：自动通过 CLI v2 读取和创建原生卡片，保留标题、链接及原位置，不再因此中断整篇剪存。
- 正文尚在加载：等待正文出现并稳定后再读取；超时会提示回到原网页确认，继续同一任务即可。不会把加载提示保存成正文。
- 写入响应丢失、限流或查询临时失败：对已确认可安全重试的步骤自动恢复，最多重试 5 次，沿用同一文档和任务。后台进程中断后自动续接；持续失败、权限失效或真实内容差异会明确停下。
- 每次从插件打开保存页都是独立请求，只复用默认目录与已有登录；即使再次保存同一篇文章，也不会沿用上一篇的成功或失败状态。同一保存页的双击、刷新和断线恢复沿用自己的请求；保存任务互不串联，等待连接时让其他任务继续执行。
- 桌面通知由浏览器和系统通知设置控制；通知不可用不影响保存结果，剪存页仍显示完成状态。
- 图片读取失败或出现不支持的资源块：在新建文档前停止并提示具体问题；已暂存图片可继续使用。
- 迁入知识库时断线或丢失响应：后台自动查询本次文档的位置，必要时仅继续迁入同一份文档；异步处理和临时断线均无需手动重试。自动恢复期限 15 分钟、最多 5 次迁入请求，等待期间其他保存任务继续执行。权限或目标错误、飞书明确禁止重试的错误、持续故障超时才提示处理，已有文档保留。
- 新建请求结果不明：插件用本次保存的随机标记自动查找并接续已创建的空文档，最多等待 5 分钟。旧版无标记或查证超时的任务可直接点击“重新保存到飞书”，复用已读取图文开启一次新的保存，不要求手动查重或再弹确认。旧尝试记录保留；若此前请求实际已成功，可能额外留下未使用的空文档，但不会对其自动迁入或删除。
- 真正失败或达到自动恢复上限时会通知未完成，点击可返回这篇文章处理。详情中可以重试同一任务或停止重试并保留已有副本；结束任务不会撤销飞书正在处理的操作。

网页正文从当前已打开的页面读取；生财文章、公众号使用正文专用容器，Google Docs 使用原生 HTML 导出，普通文章复用正文提取器。保留标题层级、正文、图片、列表、普通表格和代码。视频、音频及附件卡片保留名称和原资源链接，不上传媒体或附件文件；页面未提供直链时，明确保留“在原网页播放/下载”的来源入口。生财播放器的图标和播放按钮不当作正文图片上传。网页外观会适配飞书排版。暂不支持画布、公式、合并单元格、未知嵌入资源和独立表格产品；遇到这些正文资源会停止并提示具体类型。网页快照最多 5000 块、700 KiB（含内嵌 dataURL 图片），单张图片最多 20 MiB。图片不能读取时不生成缺图文档，本地导出仍可单独使用。

配置、权限、恢复机制与验收方法见 [飞书知识库剪存说明](docs/feishu-wiki-clip.md)。

## 功能概览

### 1. 单篇导出

支持：

- 飞书 `docx/wiki`
- Google Docs `https://docs.google.com/document/d/*`
- 微信公众号文章页 `https://mp.weixin.qq.com/s/*`

可选：

- 导出 `Markdown`
- 导出 `JSON`
- 选择是否包含正文图片

### 2. 链接列表批量下载

支持一组飞书 / 微信文章链接批量导出为 Markdown。

当前行为：

- 自动打开独立任务页执行
- 默认串行下载
- 默认带节流和失败重试
- 默认打包为一个 ZIP
- ZIP 内附带：
  - `manifest.json`
  - `articles.txt`
  - `failed.txt`（仅失败时生成）

### 3. 公众号范围批量下载

输入：

- 该公众号任意一篇种子文章链接
- 开始日期
- 结束日期

能力：

- 复用当前 Chrome 里的 `mp.weixin.qq.com` 登录态
- 自动搜索目标公众号
- 自动拉取同号历史文章列表
- 按日期范围过滤后进入批量下载队列

不需要：

- 系统代理
- 手机微信
- mitmproxy
- 手动复制历史文章链接

### 4. 生财课程专栏导出

输入：

- 当前已打开的生财航海活动课程页，例如 `https://scys.com/activity/.../course/...?...chapterId=...`
- 也兼容 `https://scys.com/deepsea/.../course/...?...chapterId=...` 和 `https://scys.com/course/detail/...?...chapterId=...`

能力：

- 自动识别当前专栏左侧目录
- 串行导出当前专栏全部可访问章节
- 最终输出两个单文件：
  - `专栏名.md`
  - `专栏名.html`

适合：

- 把整专栏丢给 NotebookLM / 其他 AI
- 导入 Obsidian
- 本地离线浏览

## 快速开始

### 安装

1. 打开 `chrome://extensions/`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目目录

如果你更新了代码：

1. 回到 `chrome://extensions/`
2. 点击扩展“刷新”
3. 把对应网页也刷新一次

### 默认下载位置

文件会直接保存到 **Chrome 当前默认下载目录**。

可在这里查看：

- `chrome://downloads/`
- `chrome://settings/downloads`

## 使用说明

### 单篇导出

1. 打开飞书文档、Google Docs 或微信公众号文章页
2. 点击扩展图标
3. 选择是否“Markdown 包含图片”
4. 点击“导出 Markdown”或“导出 JSON”

说明：

- 飞书 `Markdown` 走 `client_vars -> block_map -> Markdown`
- Google Docs `Markdown` 走文档原生 HTML 导出，不读取画布化编辑器 DOM；支持当前 `tab`，并保留标题、链接、列表、表格和可选图片；HTML 解析受浏览器安全策略拦截时会自动回退到纯文本正文
- 公众号 `Markdown` 走正文 HTML 提取与清洗
- 公众号带图模式会把图片转成内嵌 `data:` URL

### 生财课程专栏导出

1. 打开任意一个生财课程章节页
2. 点击扩展图标
3. 确认弹窗里出现“导出当前专栏”
4. 点击后扩展会自动打开任务页
5. 任务完成后自动下载：
   - 一个整专栏 `Markdown`
   - 一个带目录导航的 `HTML`

说明：

- 航海活动页会自动定位并注入内层课程 iframe，无需手工打开 `/course/detail/...` 地址
- 支持 `scys.com/activity/.../course/...`、`scys.com/deepsea/.../course/...` 和 `scys.com/course/detail/...` 章节页
- 旧的单篇导出和手工批量下载逻辑不变
- 如果某些章节失败，最终文件仍会生成，并附带失败章节列表

### 链接列表批量下载

1. 打开扩展
2. 在“批量下载”里每行粘贴一个链接
3. 点击“批量下载链接列表”
4. 扩展会自动打开独立任务页
5. 任务页完成后，浏览器开始下载 ZIP 或 Markdown 文件

说明：

- 批量任务不再依赖弹窗保持打开
- 不要手动关闭任务页
- 公众号批量下载优先尝试“直接抓 HTML 再解析”
- 如果微信返回“环境异常 / 去验证”页，会自动回退到稳定页面模式

### 公众号范围批量下载

1. 先确保当前 Chrome 已登录 `https://mp.weixin.qq.com/`
2. 如果没登录，在扩展里点击“打开后台登录页”
3. 在“公众号后台模式”里填入：
   - 种子文章链接
   - 开始日期
   - 结束日期
4. 点击“检测后台登录”
5. 点击“按范围批量下载”

## 当前推荐使用方式

### 飞书

最稳妥的使用范围：

- `https://*.feishu.cn/docx/*`
- `https://*.feishu.cn/wiki/*`
- `https://*.larksuite.com/docx/*`
- `https://*.larksuite.com/wiki/*`
- `https://*.larkoffice.com/docx/*`
- `https://*.larkoffice.com/wiki/*`

当前不支持：

- `sheet`
- `bitable/base`
- `minutes`
- `file`
- 任意修改既有文档（知识库剪存只写入本次新建的文档）

### 微信公众号

当前稳定支持：

- 单篇文章导出
- 后台登录态下的范围批量下载

当前不支持：

- 只输入公众号昵称直接抓整号历史
- 评论、阅读量、点赞、分享等后台统计数据

### Google Docs

当前支持：

- 有查看权限的原生 Google 文档
- 当前文档标签页的 `Markdown / JSON` 导出
- 原生导出中的标题、链接、列表、表格和图片

当前不支持：

- Google Sheets / Google Slides
- 无查看权限或需要重新登录的文档

如果导出的文件仍然为空，或只出现“匹配文档格式”“正在加载”等编辑器界面文字：

1. 打开 `chrome://extensions/`
2. 找到“文档本地导出”，点击“刷新”
3. 回到 Google 文档页面并刷新网页
4. 再次打开扩展，确认页面类型显示为“Google 文档”，主按钮显示“导出当前 Google 文档”
5. 先关闭“Markdown 包含图片”做一次快速导出；确认正文正常后，再按需开启图片留档

成功标志：导出的 Markdown 包含文档正文，不再包含 Google Docs 工具栏、侧边栏或加载提示文字。

### 生财课程

当前稳定支持：

- 当前课程专栏整包导出
- 单个 `Markdown` 文件输出
- 单个 `HTML` 阅读版输出

当前不支持：

- 整个课程专区全量抓取
- 多专栏批量导出
- PDF 导出

## 已知限制

- 公众号范围下载依赖你自己的 `mp.weixin.qq.com` 登录态
- 微信有时会对直接 HTML 抓取返回验证页，这时会自动回退到页面模式
- 批量下载期间需要保持独立任务页打开
- Markdown 是“可读优先”的本地导出，不追求 100% 样式还原

## 项目结构

当前仓库保留的是 **真正会参与运行的 MVP 源码**。

主要文件：

- `manifest.json`：扩展入口与权限
- `popup.html` / `popup.css` / `popup.js`：扩展弹窗与主交互
- `batch-runner.html` / `batch-runner.css` / `batch-runner.js`：批量任务页
- `background.js`：图片抓取与后台消息
- `wechat-direct-export.js`：公众号 HTML 直抓解析模块
- `content-scripts/feishu-exporter.js`：飞书、Google Docs、公众号和普通网页内容提取主逻辑
- `icon/`：扩展图标
- `_locales/zh_CN/messages.json`：本地化资源

## 实验性方案

仓库仍保留一个实验性目录 [`helper/`](./helper/)。

它是旧的“微信客户端 + mitmproxy + helper”抓取方案，仅用于研究，不是主流程。

主流程优先使用浏览器里的公众号后台模式。

## 后续方向
