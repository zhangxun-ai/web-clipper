# UI 审核与优化记录

2026-09-08。范围为当前有效的插件弹窗、飞书保存页和批量任务页；历史商店产物不在此次修改范围内。

## 审核结论与实际调整

| 维度 | 原问题 | 本次调整 |
| --- | --- | --- |
| 文案 | “分类工作台”“当前页主操作”等内部表达占据主界面，说明多次重复 | 以文章标题、导出方式、保存位置和具体动作组织内容；精简重复说明，保留权限、图片体积和首次连接等必要信息 |
| 字体 | 标题、提示、面板标题接近，英文眉题与中文界面割裂 | 使用系统中文字体，不引入外部字体请求；弹窗品牌 18px、文章标题 19px、操作及正文 12–13px，11px 仅用于短辅助标签 |
| 布局 | 固定 452px 弹窗触发 `max-width: 460px` 样式，分类、预设和按钮全部变单列 | 修复断点，预设保持三列，主操作保持两列；批量工具和 Obsidian 目录按需展开 |
| 颜色 | 大面积黄棕渐变、重阴影及多层着色，让所有信息都显得重要 | 保留暖色识别，使用浅灰米色背景、白色内容区；棕色只强调主要动作与选中状态，绿色用于成功、红色用于错误 |
| 间距 | 嵌套卡片反复消耗弹窗宽度，正文与关键操作距离过远 | 移除主界面嵌套卡片；采用 4/8/12/16/20/24px 间距，相关内容紧凑分组，区块通过留白和细分隔线区分 |
| 信息层级 | 文章标题被埋在元数据中，保存结果与批量进度位置靠后 | 首屏呈现文章、方式、主按钮；飞书任务进度和结果位于表单上方，批量进度优先于日志和通道详情 |
| 键盘与反馈 | 设置链接不能可靠展开控件，分类缺少方向键交互，折叠后错误恢复入口不易找到 | 设置链接展开并聚焦；分类支持方向键/Home/End，更新选中状态与面板标签；缺少 Obsidian 授权时自动展示目录入口；保留可见焦点、状态播报与减少动态效果偏好 |

另外复现并修复公众号后台错误显示“停止导出”的问题：现在只有实际进行中的单篇导出会显示取消动作，后台页的主按钮正常展开日期范围工具。专栏识别期间禁用导出，不再显示无法执行的取消动作。

## 全页面文案精简

按追加要求，对三个实际使用页面进一步精简：

- 弹窗去掉宣传语、重复的预设选中提示、分类解释及飞书入口说明；普通文章不再重复介绍按钮已经表达的能力。批量工具去掉“尚未开始”等空状态提示和重复的说明卡片，表单标签与占位提示各司其职。Obsidian 的状态与目录名各展示一次。
- 飞书页去掉重复连接说明与成功后的第二个打开按钮。完成后来源表单默认收起，仍可展开查看或修改；轮询不会收起用户已展开的表单，更换来源后重新显示保存操作。
- 批量页去掉三个与原有结果、折叠详情重复的“查看”按钮。首屏只显示进度、成功、失败和用时；通道配置留在详情与日志。任务未加载时不显示无意义的 0 / 0 统计，失效任务明确提示重新从插件开始。
- 保留具体错误、重试动作、读取原网页的要求、权限说明与完整诊断日志。

## 共享样式

`shared/ui-tokens.css` 统一三页的颜色、字体、圆角、焦点和基础可访问性样式。无新增运行依赖、远程字体、图片请求或扩展权限。

- 背景 `#f6f5f2`，内容区 `#ffffff`，主要文字 `#292722`，辅助文字 `#706b63`。
- 主色 `#965415`，成功 `#246344`，错误 `#a33434`。
- 内容区圆角 12px，按钮与输入框圆角 8px；状态切换使用短颜色过渡，不移动按钮。

- **现有 JavaScript**：`npm test`，197 项通过。
- **飞书浏览器回归**：原有 `feishu-extension.cjs` 和 `feishu-recovery.cjs` 通过。覆盖图文读取、记忆目录、逐篇保存、失败恢复、响应丢失、后台重启及迁入恢复；飞书响应使用模拟数据，没有写入真实知识库。
- **视觉状态**：查看了保存前、完成、首次安装、连接失败，以及批量任务的缺失任务、完成和长内容错误状态。保存页检查桌面、390px 和 320px，批量页检查桌面、390px 和 320px。批量完成与长内容状态使用展示夹具，只验证排版，不代表真实下载结果。

- **语法与补丁**：`node --check popup.js`、`node --check background.js`、`node --check feishu-save.js`、`git diff --check` 通过。
- **设计扫描限制**：Impeccable 检测器缺少 HTML/CSS 解析模块，自动降级为正则扫描；输出没有发现项，但未执行选择器和对比度计算。上述浏览器渲染与对比度检查独立执行。
