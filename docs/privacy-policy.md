# 文档本地导出 - 隐私政策

最近更新：2026-09-08

## 1. 插件用途

本插件用于将以下内容导出到用户本地设备：

- 飞书 `docx/wiki` 文档
- 微信公众号文章
- 用户在当前 Chrome 浏览器中已登录的微信公众号后台历史文章列表

用户也可以主动将当前打开的生财文章、公众号、普通网页、Google Docs 和飞书文档的正文和图片，重建为自己的文档并保存到选择的知识库父页面下。

## 2. 我们处理哪些数据

插件只处理完成功能所必需的数据，包括：

- 当前页面中的文档内容、文章正文、图片链接
- 用户在插件中输入的文章链接、日期范围等操作参数
- 浏览器本地保存的插件设置，例如是否包含图片
- 用户选择的飞书知识库、父页面及剪存进度记录（包含原文、副本和迁入任务标识）

## 3. 数据如何使用

这些数据仅用于以下目的：

- 将页面内容导出为 Markdown
- 批量下载用户明确选择的文章
- 在用户已登录公众号后台时，查询并下载指定日期范围内的历史文章
- 根据用户选择，在飞书创建文档副本并迁入指定知识库

## 4. 数据存储与传输

- 插件默认将导出结果保存到用户本地下载目录
- 插件使用 `chrome.storage.local` 保存本地设置和批量任务信息
- 飞书剪存完成时通过浏览器桌面通知显示文章标题和保存位置，最终失败时通知该文章尚未完成；通知对应的任务标识、来源/目标或结果链接与发送状态保存在本地，用于点击打开和避免重复通知。
- 新文档创建时使用随机临时标题关联本次保存；请求中断后读取本人云空间根目录的文件元数据，精确匹配并核对本次文档后恢复处理。不会为此读取不相关文档正文。内容核对后恢复原文章标题。
- 插件不会将飞书文档正文、公众号正文、批量下载结果上传到开发者服务器
- 飞书知识库剪存通过用户安装的本机 Native Messaging 连接器调用飞书 CLI，直接访问飞书官方服务。本机连接器保存原网页网址、内容块快照、图片文件和用于恢复及避免重复创建的操作记录，文件仅对当前本机用户开放。任务结束后这些恢复文件仍保留在连接器状态目录中，用户可自行管理。
- 飞书应用密钥和登录令牌由本机 CLI 管理，不存入扩展。临时登录设备码只保存在本机权限受限的文件中，授权完成后清空；扩展只接收官方授权链接。

## 5. 第三方服务与网络请求

插件会直接访问以下用户正在使用或用户明确触发的站点：

- `feishu.cn`
- `larksuite.com`
- `larkoffice.com`
- `mp.weixin.qq.com`
- `scys.com`、`docs.google.com`
- 用户主动保存的当前网页及其正文图片资源域名

这些请求用于读取页面内容、查询公众号后台历史文章、下载文章图片，以及在用户主动剪存时新建文档、写入正文、上传图片及迁入知识库。授权和剪存还会访问飞书官方开放平台及账号服务。

## 6. 我们不做的事情

- 不出售用户数据
- 不将文档正文或文章正文上传到开发者自有服务
- 不做广告追踪
- 不读取与插件功能无关的网页内容

## 7. 用户控制

用户可以随时：

- 卸载插件
- 删除浏览器下载目录中的导出文件
- 清除 Chrome 扩展本地存储中的设置与任务记录
- 在飞书中管理已保存的副本及权限，并通过飞书 CLI 管理或撤销授权
- 结束已停止的剪存任务，保留已创建的副本；卸载扩展不会自动删除飞书副本、本机连接器或 CLI 授权记录
